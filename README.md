#  StudyFlow

StudyFlow is a simple productivity app made to help manage time, study sessions and daily tasks
in one place.

## Features

-  Time Tracker with categories, daily goals and streaks
-  Week and Calendar views for tracking progress
-  Countdown Timer for different categories
-  One-time and repeating Alarms
-  Reminders with notifications and voice alerts
-  World Clock for different countries
-  Daily Planner with goals, editing and pinning
-  Multiple themes
-  Export and  Import of tracked time data
-  Responsive design for smaller screens

## Privacy

StudyFlow does not use an account or server. Your data is stored locally in your browser using 
local storage.
